# Claude Code: Software Engineering with Generative AI Agents

A collection of example projects and code samples accompanying the Coursera specialization **[Generative AI for Software Engineering](https://www.coursera.org/specializations/generative-ai-software-engineering)**.

---

## About This Repository

This repository contains hands-on examples and exercises that demonstrate how to use **Claude Code** — Anthropic's AI-powered coding agent — throughout the software development lifecycle. Each example maps to key concepts taught in the Coursera specialization, covering everything from writing and refactoring code to automated testing and debugging with generative AI.

---

## About the Course

The **Generative AI for Software Engineering** specialization on Coursera teaches how to leverage large language models (LLMs) and AI agents to supercharge software development workflows. Topics include:

- Using AI coding assistants for code generation and completion
- Automating code reviews, refactoring, and documentation
- AI-assisted debugging and test generation
- Building and orchestrating AI agents for complex engineering tasks
- Best practices for prompt engineering in a software engineering context

## Prerequisites

- [Claude Code](https://claude.ai/code) (Anthropic's CLI coding agent)
- Python 3.9+ or Node.js 18+ (depending on the example)
- A Coursera account enrolled in the [Generative AI for Software Engineering](https://www.coursera.org/specializations/generative-ai-software-engineering) specialization

## Getting Started

1. **Clone this repository**
   ```bash
   git clone https://github.com/Cyber-Seowon-Foundation/coursera_claude_code.git
   cd coursera_claude_code
   ```

2. **Install Claude Code** (if not already installed)
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

3. **Browse the examples** — each subdirectory contains its own `README.md` with instructions specific to that module.
